## 一、数据

本任务集**不包含任何实测数据**。公式与变量语义取自公开物理定律，采样点由本队按 `meta.json` 声明的区间独立生成。
这样做的理由：真实实验数据缺少公认的标准答案，无法客观判定对错；而本赛事要求作品可验证，必须有客观答案才能形成闭环。

### 1.2 逐任务的公式与变量语义来源

每个任务的标准公式与变量含义取自对应公开物理定律条目；`tasks/<id>/meta.json` 的 `source` 字段保存同一链接，`reference/<id>.json` 亦逐条登记。

| 任务 | 描述的现象 | 来源 |
|---|---|---|
| `phys-buoyancy` | 浮力等于排开液体的重量 | [阿基米德原理](https://en.wikipedia.org/wiki/Buoyancy) |
| `phys-coulomb` | 两静止点电荷间作用力与电量乘积成正比、与距离平方成反比 | [库仑定律](https://en.wikipedia.org/wiki/Coulomb%27s_law) |
| `phys-cyclotron` | 带电粒子回旋角频率与磁感应强度成正比、与质量成反比 | [回旋共振](https://en.wikipedia.org/wiki/Cyclotron_resonance) |
| `phys-elastic-pe` | 弹性势能随形变量与劲度系数的组合变化 | [弹性势能](https://en.wikipedia.org/wiki/Elastic_energy) |
| `phys-energy-shift` | 能级差决定的光子频率 | [普朗克关系式](https://en.wikipedia.org/wiki/Planck_relation) |
| `phys-grav-potential-energy` | 两质点间引力势能与距离成反比 | [引力势能](https://en.wikipedia.org/wiki/Gravitational_energy) |
| `phys-gravitation` | 两质点间引力与质量乘积成正比、与距离平方成反比 | [万有引力定律](https://en.wikipedia.org/wiki/Newton%27s_law_of_universal_gravitation) |
| `phys-hydrogen-level` | 氢原子束缚态能级与主量子数平方成反比 | [玻尔模型](https://en.wikipedia.org/wiki/Bohr_model) |
| `phys-ideal-gas` | 理想气体压强与物质量、温度成正比，与体积成反比 | [理想气体状态方程](https://en.wikipedia.org/wiki/Ideal_gas_law) |
| `phys-index-vacuum` | 介质折射率与介电常数、磁导率的关系 | [折射率](https://en.wikipedia.org/wiki/Refractive_index) |

| `phys-pendulum-exact` | 有限振幅单摆的精确周期（小角度近似的修正项） | [单摆（大摆角修正）](https://en.wikipedia.org/wiki/Pendulum_(mechanics)) |
| `phys-pendulum-period` | 小角度单摆周期与摆长平方根成正比、与重力加速度平方根成反比 | [单摆（小角度）](https://en.wikipedia.org/wiki/Pendulum_(mechanics)) |
| `phys-radioactive-decay` | 放射性衰变中剩余原子核数量随时间指数衰减 | [放射性衰变](https://en.wikipedia.org/wiki/Radioactive_decay) |
