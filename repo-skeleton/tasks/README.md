## 难度分层标准（自定，需在说明书中引用）

- **base（基础层）**：变量数 ≤ 3，表达式仅由四则运算与幂函数构成，无需量纲推理即可判断合理性。
- **challenge（挑战层）**：变量数 4—5，或含复合函数（三角函数、指数、对数、根式），或必须借助量纲/尺度推理才能排除错误候选。

## 数据划分规范

1. **训练集**：智能体可见，用于拟合参数。
2. **留出集**：同一支撑域内随机留出，智能体**不可见**，用于检验插值精度。
3. **外推区**：位于支撑域之外（例如将自变量范围扩展到训练区间的 1.15 倍），智能体**不可见**，用于检验"是真发现还是纯拟合"。
4. 划分结果固定并落盘（`split.json`），保证任何一次重跑使用同一划分。

> **红线**：标准公式文件 `reference.json` 仅供评分脚本读取，**不得进入智能体的任何输入或上下文**。
