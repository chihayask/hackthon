# FORMULA-AGH v0.2.1

本版相对 v0.2.0 的变化。**核心新增是一条完整的仿真任务线**，用于回应赛题方向
「科学计算与仿真」及其示例（公开温度场 → 反演参数 → 仿真复现 → 边界条件对比）。

## 一、新增仿真任务线（`sim/`）

| 项 | 内容 |
|---|---|
| 数据 | NASA GISTEMP v4 纬度带年平均温度异常（**公开真实观测**），8 个纬度带、1880—2025；取数脚本记录 sha256 |
| 模型 | 一维能量平衡模型 `C dT/dt = d/dx[(1-x^2) D dT/dx] - lambda*T`（North 度量形式） |
| 数值 | 非均匀网格有限体积 + 隐式欧拉；极面零通量由度量系数内建，**守恒残差 7.2e-16** |
| 反演 | 对离散 PDE 残差做线性最小二乘（闭式解，两参数同时辨识） |
| 边界条件 | neumann / dirichlet / robin 三种 |
| 对照 | 持久基线与零距平基线；另做第二个年份划分核对稳定性 |

三条结论（数字由 `sim/results.json` 自动生成，见 `sim/RESULTS.md`）：

1. **边界条件的处理方式显著改变反演结果**：dirichlet 的离散 PDE 残差约为另两种的 45%，
   且在两个不同年份划分下都稳定；
2. **robin 被诊断为模型误设**：两个划分下都反演出负扩散系数（非物理），加非负约束后
   最优解退化到 kd = 0 且残差变差——是设定错误，不是参数没调好；
3. **向前预报未稳定优于持久基线**，文档如实写明。

## 三、AGH 环境的两种失败模式（都已定位并加了防御）

| 失败模式 | 症状 | 处置 |
|---|---|---|
| 目录不私有 | 任何命令报「凭证库不可用」 | `harness/fix_agh_acl.cmd`（该 ACE 会复发，故做成脚本） |
| **死代理** | `doctor profile` 与 `doctor provider --probe` **都通过**，只有推理失败 | 驱动脚本运行前探测代理端口，不通即清空代理并重启守护进程 |

第二种尤其隐蔽：探测走进程内、推理走守护进程，两者环境不同，会出现「探测正常、推理失败」的矛盾。
