你负责一个参数反演与边界条件对比任务。工作目录是你的工作区，里面有 sim/ 目录。

## 数据

sim/data/zonal_bands.csv 是 NASA GISTEMP 公开的纬度带温度异常（1880—2025，8 个纬度带，
自南向北）。这是真实公开观测，不是合成数据。

## 模型

待反演的是**一维能量平衡模型**：

    C dT/dt = d/dx[ (1-x^2) D dT/dx ] - lambda * T ,   x = sin(latitude)

状态已取为**距平**：T_i = 纬度带温度 − 全球面积加权均值（减去全球均值可消去外强迫的一阶响应）。
未知量是两个比值：kd = D/C、kl = lambda/C。

极点边界有三种处理方式：

* neumann  ：极面零通量（球面度量自带，g(x)=1-x^2 在极点恰为 0）；
* dirichlet：极点带钉在观测值上，不作为待预测量；
* robin    ：极点与外部储库按固定系数交换热量。

## 你唯一的工具

必须原样照抄下面这条命令（绝对路径、不加引号、不要用 cmd /c、不要加管道或重定向）：

    {{PROBE}} --bc <neumann|dirichlet|robin> --fit

它返回**单行 JSON**，字段含义：

* `identified.kd` / `identified.kl`：最小二乘反演出的参数；
* `pde_residual_rmse`：离散 PDE 的残差（越小说明该模型越自洽）；
* `forward_rmse`：用该参数正向仿真，误差随预报时效（逐年）；
* `persistence_rmse`：持久基线（预测下一年等于今年）在同一起报期的误差；
* `climatology_rmse`：零距平基线的误差。

也可以给定参数而不是让它拟合：加 `--kd 0.02 --kl 0.4` 替代 `--fit`。
